# Mixel Remote Bug Hunt — 2026-11-20

Full UI/UX (macOS, Windows, Linux) and Backend (Rust engine, signaling server, SQL/RLS) audit after `2.1.10`.

## Fixed in `2.1.11` (and SQL `034`)

| Sev | Area | Bug | Fix |
|---|---|---|---|
| **P0** | SQL / Tenant Isolation | `remote_quick_phone_claim` (`032`) allowed any authenticated user in Tenant B to hijack or un-revoke a Quick Support device already saved/owned by Tenant A, and let suspended SaaS tenants fall back to Mixel's shared client. | `next/sql/034_harden_quick_support_and_save_device.sql` applied on `ism-postgres` (`ism` DB): blocks cross-tenant hijacking of saved/revoked Quick Support devices and blocks suspended/read-only SaaS tenants from falling back to `quick_phone_client()`. |
| **P1** | SQL / AuthZ | `remote_save_connected_device` (`033`) checked `can_read_device` instead of admin/technician privileges, bypassed `require_feature(tenant, 'groups')`, skipped audit logging, and could exceed 60 chars on disambiguated names. | `034`: requires active subscription + `owner`/`admin`/`technician` (SaaS) or staff/`can_admin_device` (ISM), gates group creation with `require_feature(..., 'groups')`, truncates base name to 54 chars before `' (n)'`, and writes `remote_private.device_admin_audit`. |
| **P1** | Backend / Engine | Failed make-before-break renewal race (`ServerMessage::Signal` arriving after failed renewal dropped its receiver) returned `Err` via `?` out of the main signaling loop, killing the WebSocket and all live sessions. | `next/crates/mixel_engine/src/remote_session.rs:4482`: drop stray signals to closed/full peer queues instead of aborting the signaling WebSocket. |
| **P1** | Backend / Engine | `start_warm` silently dropped an adopted `Config` if `prepare_warm` failed/timed out after `adopt`, hanging the connection for 60s. | `next/crates/mixel_engine/src/remote_peer.rs:333-346`: fall back immediately to `own_media(config, ..., None)` if `adopted.try_recv()` has a waiting `Config`. |
| **P1** | Backend / Protocol | `parse_features` only accepted ASCII alphanumerics, stripping `"clip-same"` (contains `-`) from every SDP offer/answer and disabling unchanged-clipboard deduplication. | `next/crates/mixel_engine/src/remote_peer.rs:655`: allow `b'-'` in SDP feature tokens. |
| **P1** | macOS UI/UX | `AppModel.start()` called `host.checkPermissions(promptIfMissing: true)` before `refreshRemote()`, when `RemoteStatus.offline` defaulted `inputAccess = true`, so Accessibility was never prompted on fresh Macs. | `AppModel.swift:138`: await `refreshRemote()` before `checkPermissions(promptIfMissing: true)`. |
| **P1** | macOS / Windows UI/UX | Clicking "End session" on the hosted-session banner / menu bar called `app.session.end()`, closing the technician's outgoing session instead of the incoming shared session when both were active. | `HostModel.swift:160`, `RootView.swift:107,534`, `MainWindow.cs:291`: end `idleSession` / `IdleSession` (`host.stopSharing()`) for hosted sessions. |
| **P1** | macOS UI/UX | Clicking Quick Support fired `quick_support_start` twice concurrently (button tap + `QuickSupportConsoleView.onAppear`). | `AppModel.swift:391-410`: added `quickSupportStarting` in-flight guard. |
| **P2** | macOS / Windows UI/UX | Holding a key during a brief network hiccup filled the 64-item input queue and called `remote_close`, killing the live session. | `SessionModel.swift:336`, `SessionModel.cs:358`: drop oldest queued event instead of terminating the session. |
| **P2** | macOS UI/UX | Compressed H.264 burst drain loop discarded an already-decoded `latest` frame if a subsequent drained frame threw `waitingForKeyframe`. | `SessionModel.swift:244-258`: isolate drain errors so `latest` is always shown. |
| **P2** | macOS / Windows / Linux UI/UX | Save Device dialog pre-filled `Device name *` with the raw Connection ID on unsaved devices, kept stale `target_client` when typing a new company (macOS), and Linux only checked page 1 (`devices`) instead of `company_all`. | Fixed in `AdminDialogs.swift`, `MainWindow.Chrome.cs`, `mixel-remote-linux/src/app.rs`. |
| **P3** | macOS / Windows UI/UX | `MainWindow` shifted 28pt when a popped-out session window entered full screen; Windows `UpdateNotice` dismiss button had an empty glyph `""`. | Fixed in `Mac/MixelRemoteApp.swift:72-77` and `MainWindow.Chrome.cs:341`. |
